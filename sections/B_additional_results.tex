\subsection{Per-Season Empirical Coverage}
\label{app:empirical_coverage}

Figure~\ref{fig:empirical_food_coverage} shows per-season
empirical coverage for the food-at-home IPCA application
($T_s = 20$, $n_s = 10$ per season in the test period).
Because each bar is based on only ten observations,
standard errors are $\approx 0.14$; the pattern should be
read in conjunction with the simulation results of
Experiment~E2 (Table~\ref{tab:e2_stratum_size}), which
provide the finite-sample reference distribution.

\begin{figure}[ht]
  \centering
  \includegraphics[width=0.85\textwidth]{figures/fig_empirical_food_coverage}
  \caption{Per-season empirical coverage for food-at-home IPCA
           forecasting (test: 2015--2024).
           The horizontal dashed line is the $90\%$ nominal level.
           Each bar is based on $n_s = 10$ observations;
           individual bars carry standard errors of $\approx 0.14$.}
  \label{fig:empirical_food_coverage}
\end{figure}
